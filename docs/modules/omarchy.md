# Omarchy

Linux only (`.chezmoiignore` skips `~/.config/omarchy` on other OSes). Managed through chezmoi like the other modules.

| Source (`chezmoi/dot_config/omarchy/`) | Target |
| --- | --- |
| `shell.json` | `~/.config/omarchy/shell.json` — idle/lock timers, bar layout |
| `plugins/builtby.leader/` | `~/.config/omarchy/plugins/builtby.leader/` — `jk` leader bar indicator |

Apply: pick "Omarchy" in `bb setup`, or run `scripts/apply-chezmoi.sh ~/.config/omarchy/shell.json ~/.config/omarchy/plugins/builtby.leader`. The omarchy shell hot-reloads `shell.json` on save.

## Idle and lock

`idle.screensaver` and `idle.lock` are seconds of idle time; `0` disables the action. Both are `0` here, so the screen never auto-locks. Manual lock (`omarchy system lock`) still works.

## Keeping the repo in sync

`omarchy` commands (`omarchy bar put`, `omarchy plugin enable`, the settings panel) rewrite `~/.config/omarchy/shell.json` in place, and the next apply overwrites those edits. Pull live changes back into the repo first:

```bash
chezmoi --source ~/dotfiles/chezmoi re-add ~/.config/omarchy/shell.json
```

Not managed on purpose: `hooks/` and `branding/` (generated by omarchy itself) and `extensions/omarchy-menu.jsonc` (stock stub). Add them if you customise them.
