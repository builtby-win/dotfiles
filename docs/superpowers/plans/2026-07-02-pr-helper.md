# PR Helper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `pr()` shell function that auto-commits a dirty worktree as `wip: <branch>`, then pushes and creates or reuses the GitHub PR from the current worktree.

**Architecture:** Keep the logic inside `shell/functions.sh`, where the other shell helpers live. `shell/init.sh` already sources that file, so no bootstrapping changes are needed. The function stays branch-local, uses only `git` and `gh`, and returns early on detached HEAD or missing `gh`.

**Tech Stack:** Bash, Git, GitHub CLI (`gh`).

## Global Constraints

- Operate on the current git worktree only.
- Use the current branch name from `git`.
- Fail fast if not inside a git repo or if HEAD is detached.
- If the worktree has changes, stage everything and create a `wip: <branch>` commit before pushing.
- Push the current branch to `origin` on every invocation.
- After the push, if an open PR already exists for that branch, print its URL and exit.
- If no open PR exists, create one with `gh pr create --fill` against the repo’s default branch.
- Keep the function self-contained; no new script file, no extra wrapper command, no new flags.
- Use `command git` / `command gh` so shell aliases do not interfere.
- Keep the logic branch-local: no branch switching, no worktree discovery, no cross-branch syncing.

- [ ] **Step 1: Add the function**

```bash
pr() {
  command -v gh >/dev/null 2>&1 || {
    echo "pr: gh is not installed."
    return 1
  }

  command git rev-parse --is-inside-work-tree >/dev/null 2>&1 || {
    echo "pr: not inside a git repo."
    return 1
  }

  local branch pr_url
  branch="$(command git branch --show-current)"
  if [[ -z "$branch" ]]; then
    echo "pr: detached HEAD."
    return 1
  fi

  if [[ -n "$(command git status --porcelain --untracked-files=all)" ]]; then
    command git add -A || return 1
    if command git diff --cached --quiet --ignore-submodules --; then
      echo "pr: nothing to commit."
      return 1
    fi
    command git commit -m "wip: $branch" || return 1
  fi

  command git push -u origin HEAD || return 1

  pr_url="$(command gh pr list --head "$branch" --state open --json url --jq '.[0].url // empty')"
  if [[ -n "$pr_url" ]]; then
    printf '%s\n' "$pr_url"
    return 0
  fi

  command gh pr create --fill
}
```

tmpdir="$(mktemp -d)"
cat >"$tmpdir/git" <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
case "$1 $2 $3" in
  "rev-parse --is-inside-work-tree")
    exit 0
    ;;
  "branch --show-current")
    printf '%s\n' feature/pr-helper
    ;;
  "status --porcelain --untracked-files=all")
    printf '%s\n' " M README.md"
    ;;
  "add -A")
    : "${ADD_CALLED:?}"
    : >"$ADD_CALLED"
    exit 0
    ;;
  "diff --cached --quiet")
    exit 1
    ;;
  "commit -m")
    : "${COMMIT_CALLED:?}"
    : >"$COMMIT_CALLED"
    printf '%s\n' "committed"
    exit 0
    ;;
  "push -u")
    : "${PUSH_CALLED:?}"
    : >"$PUSH_CALLED"
    exit 0
    ;;
  *)
    exit 0
    ;;
esac
EOF
cat >"$tmpdir/gh" <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
case "$1 $2" in
  "pr list")
    printf '%s\n' "${PR_LIST_OUTPUT:-}"
    ;;
  "pr create")
    : "${CREATE_CALLED:?}"
    : >"$CREATE_CALLED"
    printf '%s\n' "${PR_CREATE_OUTPUT:-created}"
    exit 0
    ;;
  *)
    exit 0
    ;;
esac
EOF
chmod +x "$tmpdir/git" "$tmpdir/gh"
PATH="$tmpdir:$PATH"
export PATH

ADD_CALLED="$tmpdir/add.called"

PUSH_CALLED="$tmpdir/push.called"
CREATE_CALLED="$tmpdir/create.called"
PR_LIST_OUTPUT=""

export ADD_CALLED COMMIT_CALLED PUSH_CALLED CREATE_CALLED PR_LIST_OUTPUT PR_CREATE_OUTPUT

out="$(source shell/functions.sh; pr)"
[[ "$out" == "created" ]]
[[ -f "$tmpdir/add.called" ]]
[[ -f "$tmpdir/commit.called" ]]
[[ -f "$tmpdir/push.called" ]]

PR_LIST_OUTPUT="https://example.com/pr/1"
unset PR_CREATE_OUTPUT
export PR_LIST_OUTPUT

out="$(source shell/functions.sh; pr)"
[[ "$out" == "https://example.com/pr/1" ]]
[[ -f "$tmpdir/push.called" ]]
[[ ! -e "$tmpdir/create.called" ]]
